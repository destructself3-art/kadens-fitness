## Workflow

1. Use one model and the same settings for the whole series.
2. Generate `hero` first, then `studio-cycle` (pulse light) and `zone-gym-floor` (steel light). Attach them as style references where the tool allows.
3. Coaches are one series: generate `coach-boxing` first and attach it to every other coach prompt so the backdrop, distance and light match. Only the rim colour changes: it shows the coach's usual heart-rate zone.
4. `hero-mobile` is a twin: make it by editing `hero` with the Edit prompt. Use the standalone prompt only if the tool cannot edit.
5. Reject images with visible faces, text, numbers, logos or brand marks. Models like to put logos on equipment and weight numbers on plates.
6. Highest available resolution, at least 2048 px on the long side. The exact ratio is cropped later by the photo script.
